# MindEase – Mental Wellness Consultation Platform

MindEase is a web-based Mental Wellness Consultation Platform developed as a third-year college semester project. The main objective of this project is to provide a simple and user-friendly platform where individuals can monitor their mental well-being and connect with therapists through online text-based consultations.

## Main Features

**1. Anonymous Consultation**
- Enables patients to communicate privately with therapists through text-based chat.
- Allows patients to use a nickname or anonymous display identity.
- Provides access to consultation conversations for authorized participants.

**2. Mood Tracker**
- Allows patients to record their daily moods.
- Provides an option to add notes about their feelings.
- Stores and displays previous mood entries.

**3. Session Booking**
- Allows patients to browse approved therapist profiles.
- Enables patients to request sessions by selecting a preferred date and time.
- Allows therapists to accept or reject booking requests.
- Displays booking status and upcoming sessions.

**4. Progress Dashboard**
- Displays weekly and monthly mood trends.
- Provides charts and summaries based on recorded mood entries.
- Shows consultation-related statistics to help patients review their progress.

## User Roles

- **Patient:** Can track moods, communicate with therapists, book sessions, and view progress.
- **Therapist:** Can manage their profile, review booking requests, respond to patients, and manage sessions.
- **Admin:** Can manage users and review therapist applications by approving or rejecting them.

## Technology Stack

- Next.js and React – Web application development.
- JavaScript – Programming language.
- Tailwind CSS – User interface styling.
- MongoDB Atlas – Database.
- Mongoose – Database modelling and operations.
- Auth.js – Authentication and session management.
- bcrypt/bcryptjs – Password hashing.
- Zod – Input validation.
- Lucide React – Icons.
- Recharts – Charts and data visualization.

## Project Objective and Scope

MindEase aims to make basic mental wellness management more organized and accessible through a single web-based platform. It encourages regular mood tracking, simplifies session scheduling, supports private text-based communication, and helps patients understand their progress over time.

This project is developed strictly for academic purposes. It focuses on mental wellness consultation and tracking and does not include audio or video calls, payment processing, or subscription services. It is intended as a supportive platform and not a replacement for professional mental healthcare services.

This repository contains the source code, application components, configuration files, and other resources related to the development of MindEase.
